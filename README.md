# Smart Log Analyzer

## 📌 Description
A Python-based system that analyzes log files and detects anomalies such as repeated errors.

## 🚀 Features
- Parses log files using Regular Expressions
- Counts INFO, WARNING, ERROR logs
- Detects repeated error patterns (Anomaly Detection)
- Generates summary report

## 🛠️ Technologies Used
- Python
- Regex (re module)
- Collections (Counter)

## ▶️ How to Run
1. Clone the repository
2. Run:
```bash
python main.py
